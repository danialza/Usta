# Usta Team Templates

Shareable team definitions for [Usta](https://github.com/danialza/Usta) — your AI engineering team on macOS.

A `.ustateam.yaml` file bundles a whole team: every role's system prompt, handoff topics, CLI, skills, and kickoff. Import one and your workspace instantly has a working, orchestrated team.

## Use a template

In Usta: workspace toolbar → **share icon → Import Team…** → pick the file → *Replace* or *Merge*.

## Share yours

Export from Usta (**share icon → Export Team…**), then open a PR adding it here — one folder per template with a short README describing when to use it.

## Starter templates

> Templates are plain YAML — read them before importing, like you would a shell script.
